# Meyro Gen updates

Client binaries ship as GitHub Release assets (`MeyroGen.zip` = **Meyro Gen.exe only**). This repo tracks `version.txt` only (zip is too large for git). Remote version is this repo's `version.txt` + GitHub Release tag (not inside the zip). **No source code. No Update.exe in the zip** — Update.exe is a separate GitHub Release asset fetched only when an update runs.

Token for clients: fine-grained PAT → this repo only → Contents Read-only.
